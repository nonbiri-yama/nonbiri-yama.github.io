このフォルダ（strokes/ 直下）に、クリップスタジオペイントで描いた画像をフラットに置きます。
サブフォルダは作りません。

命名規則（あ の場合）:
  あ_s01.png          … 1画目まで書いた黒字（累積）
  あ_s01_correct.png  … 1画目の正解カット（赤・矢印つき）
  あ_s01_wrong1.png   … 1画目の不正解カット（書き順が逆）
  あ_s01_wrong2.png   … 1画目の不正解カット（次の画を書いてしまう）
  あ_s02.png
  あ_s02_correct.png
  あ_s02_wrong1.png
  あ_s02_wrong2.png
  あ_s03.png
  あ_s03_correct.png
  あ_s03_wrong1.png   … 最後の画は wrong1 のみ

不正解カットの枚数は、画数によらず次の規則で自動的に決まります（js/QuestionData.js の
strokeWrongCount関数が判定するので、データ側で指定する必要はありません）。
  最後の画　　: wrong1（書き順が逆）のみ、1枚
  最後以外の画: wrong1（書き順が逆）＋wrong2（次の画を書いてしまう）、2枚

画像が未配置の間は、選択エリアに「n画目（正/誤）画像未配置」という文字だけが表示され、
出題エリアの進捗画像は非表示のまま、動作確認は行えます。
