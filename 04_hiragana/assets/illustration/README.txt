イラストエリアの背景・ランナー画像を置くフォルダ。

background1.png … 960 x 1600px。
  通常時は上から960x700pxぶんを切り出して480x350で表示。
  池シーンでは下側960x1200pxぶん（y=400〜1600）を切り出して480x600で表示。

man_run1.png / man_run2.png / man_run3.png / man_run4.png … 360 x 640px。
  走りの4フレームを150msごとに切り替える（1→2→3→4→1のループ）。
  拡大率1.0のときは135x240pxで表示し、そこから0.3〜2.0倍のあいだで拡大縮小する。
  足元が画像の下端中央に来るように描くこと。

man_fall1.png / man_fall2.png / man_fall3.png / man_fall4.png … 360 x 640px。
  不正解のときに、穴に落ちてからまた出てくるまでの4コマ（せりふ入り）。
  それぞれ次の時間だけ表示する: fall1「あー」0.4秒 → fall2「おちた」1.6秒
  → fall3「ぐぐぐ」1.5秒 → fall4「やれやれ」0.5秒（合計4.0秒）。
  この4コマにはせりふが描き込まれているので、コード側で吹き出しは出さない。
  走りフレームと同じ基準（拡大率・足元位置）で描くこと。
